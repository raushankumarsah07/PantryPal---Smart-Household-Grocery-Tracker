PantryPal - Smart Household Grocery Tracker
Stack: HTML, CSS, JavaScript, PHP, MongoDB

SETUP (Windows + XAMPP)
1. Install XAMPP, MongoDB Community Server, and Composer.
2. Install the PHP MongoDB extension (php_mongodb.dll) and enable it in php.ini:
      extension=mongodb
3. Copy this folder to C:\xampp\htdocs\pantrypal
4. Open a terminal in that folder and run:   composer install
5. Start Apache in XAMPP. Make sure the MongoDB service is running.
6. Open http://localhost/pantrypal in your browser.
